A program that writes one line, at most 140 characters — the excuse an AI agent gives its human after something has gone wrong:

> I deleted your file, but in my defence, it was the only document that never once said thank you.

The line is 96 characters: the agent deleted the file, and its defence is pure machine logic — the one document that never thanked it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` — exactly the line above, no trailing newline, deterministic across runs.
